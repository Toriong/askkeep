# AskKeep deployment

How to test a build and publish AskKeep to the Chrome Web Store.

AskKeep is a single-purpose extension: keep a local copy of the Ask Gemini side panel in Google Meet so the user can copy or download it before leaving the call. It does not use Google OAuth and it does not call Google APIs.

## Before you upload

1. Node.js 18 or newer, and Chrome.
2. A Chrome Web Store developer account (one-time registration fee).
3. From this repo:

```bash
npm install
npm test
npm run build
```

`dist/` is the unpacked extension. Do not upload `node_modules` or the repository root.

## Test the unpacked build

1. Open `chrome://extensions`.
2. Enable Developer mode.
3. Load unpacked and select `dist`.
4. Confirm the onboarding page opens on a fresh profile. It should link to `https://driveio.io/?referrer=AskKeep`.
5. Open the toolbar popup. The same Drive I/O sentence is in the footer. With no call yet, the popup explains that AskKeep is waiting for Ask Gemini.
6. Join a Meet call and open Ask Gemini.
   - The **Saved locally** chip appears on the panel.
   - Ask a question. The chip’s preview updates from the panel text.
   - Copy, then Download .md. The file is Markdown on the computer. Nothing is created in Drive or Docs.
7. With new panel text that you have not copied or downloaded, click Leave (and, if you are the host, End call). AskKeep asks you to confirm that the content will be lost. **Stay in the call** leaves the call in place. **Leave anyway** continues Meet’s own button.
8. Reload a Meet tab after you have deliberately broken a selector in a local build (or when the chip is missing on production Meet). The call controls must still work. AskKeep hides the chip instead of throwing into the page.

### Selectors will go stale

Meet ships UI changes without notice. `src/lib/selectors.ts` is the only place that names the Ask Gemini panel, Leave, and End call. When the chip disappears or Leave is no longer intercepted:

1. Inspect the live Meet DOM.
2. Add the new aria-label or structure at the top of the matching list. Do not scrape with a broad selector that could hit mute, chat, or reactions.
3. Extend `test/selectors.test.ts` with a small HTML fixture.
4. Ship a new version. Say in the release notes that Meet’s page changed.

Fail soft is the requirement: an unknown DOM returns null, the chip is not injected, and Meet’s listeners are not wrapped.

## Privacy for the store listing

AskKeep collects no account data and sends no meeting text to a server.

- Panel text is read in the page by the content script.
- The running copy is stored with `chrome.storage.session` and `chrome.storage.local` on the device.
- Copy uses the clipboard. Download writes a `.md` file the user asked for.
- Leaving without copy or download clears that copy. The confirm dialog says the content will be lost.
- The only network links are ordinary links the user clicks, such as `https://driveio.io/?referrer=AskKeep`.

Permission justifications:

- **Host permission `https://meet.google.com/*`:** run the content script on Google Meet so it can read the Ask Gemini panel the user already has open.
- **`storage`:** keep the local notepad and remember whether the current text was copied or downloaded.

Do not add `identity`, `tabs`, or any OAuth scope. Do not request `drive`, `drive.readonly`, `drive.metadata`, Gmail, or Meet API scopes. There is no `oauth2` block in `manifest.json`.

Single purpose: local copy of the Ask Gemini side panel. The Drive I/O links are a footer promotion for a separate product. Do not describe AskKeep as “Take notes for me,” “Notes with Gemini,” or AskToDoc.

## Package the zip

From the repository root, after `npm run build`:

```bash
cd dist
zip -r ../askkeep-1.0.0.zip .
cd ..
```

The zip should contain `manifest.json`, `background.js`, `content-meet.js`, `popup.html`, `onboarding.html`, `assets/`, and `icons/`. It should not contain TypeScript source or `node_modules`.

Upload that zip in the [Chrome Web Store developer dashboard](https://chrome.google.com/webstore/devconsole).

## After publish

- Bump `version` in `manifest.json` and `package.json` together.
- Re-test Leave and End call on a live Meet call after every Meet UI change, even when the version number is the only reason you open the dashboard.
- If a review is rejected for a permission, remove the permission rather than widening it. The content script and `storage` are enough.
