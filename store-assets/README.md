# Store assets

Screenshots and videos in this folder were recorded with Playwright against `demo/fixtures/mock-meet.html`.

The Meet page, the Ask Gemini panel, and the names in the notes are sample data. They are not a real meeting and not a Google account.

Regenerate with:

```bash
npm run build
npm run store-assets
```

`npm run icons` writes the 128 and 512 listing icons next to the screenshots.
